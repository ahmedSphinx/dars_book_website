# Dars Book Website

Static website for Dars Book application.

## Contents

- `index.html` - Main landing page
- `privacy.html` - Privacy policy page
- `ss.html` - Screenshots/features page
- `https_server.py` - Local HTTPS development server
- `ff.js` - Frontend utility scripts

## Getting Started

### Running Locally

To run the website locally with HTTPS:

```bash
python3 https_server.py
```

Then visit `https://localhost:8443`

## Files

- **Certificates**: `cert.pem` and `key.pem` are used for HTTPS development server
